# Contratos de datos

Los catálogos JSON son la fuente declarativa de la preimplementación.

- Misiones y evidencias describen contenido y referencias narrativas.
- Rutas, transportes y estados describen movimiento determinista.
- Recursos y operaciones describen economía y consumos.
- Personas y rescates describen identidad, requisitos y destino sin convertir personas en inventario.
- Auditoría y guardas describen trazabilidad, idempotencia y rechazo seguro.

Los esquemas bajo `schemas/` documentan las formas mínimas. El validador global comprueba existencia, JSON válido y referencias críticas.
