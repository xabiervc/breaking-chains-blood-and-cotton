# Development Roadmap

## Phase 0: Canon foundation

Complete repository documentation, stable ID policy, historical research ledger, sensitivity plan, and unresolved-question register.

## Phase 1: Narrative vertical slice

Implement the Prologue: Ashgrove, including Ezra's workshop, `BC_MISSION_PROLOGUE_IRON_LIST`, the first evidence anomaly, escape preparation, and the initial pursuit state.

## Phase 2: Refuge and pursuit slice

Implement the Great Dismal Swamp refuge, route discovery, resource costs, safe-house state, deterministic pursuit, and the first rescue-ledger entries.

## Phase 3: Investigation slice

Implement target dossiers, evidence chains, Elias Vane ambiguity, document validity, and one target resolution with multiple deterministic approaches.

## Phase 4: Regional network

Implement community management, recruitment, morale, printing, logistics, coordinated sabotage, and the final regional campaign.

## Phase 5: Research and validation

Expand sources, conduct sensitivity review, build automated schema and determinism tests, and validate all content before production.
