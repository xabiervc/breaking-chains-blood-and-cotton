# Hipótesis de prototipo

| ID | Hipótesis | Método | Criterio inicial | Si falla |
|---|---|---|---|---|
| H-001 | Compartir o proteger información produce decisiones comprensibles | Playtest con explicación posterior | 80 % identifica coste y beneficio | Reescribir feedback y UI |
| H-002 | La comunidad se percibe como agente, no como recurso | Entrevistas y revisión de representación | 80 % describe al menos una decisión comunitaria | Replantear objetivos y cámara |
| H-003 | El algodón se entiende como infraestructura de poder | Test de comprensión contextual | 75 % relaciona registros, deuda y logística | Mejorar evidencia y contexto |
| H-004 | El fracaso conserva motivación | Test de reintento | 70 % quiere probar una recuperación | Revisar consecuencias y feedback |
| H-005 | Las opciones de accesibilidad no eliminan agencia | Sesiones con usuarios diversos | Sin bloqueo narrativo por asistencia | Corregir gates y estados |

Las cifras son hipótesis de validación, no resultados observados.
