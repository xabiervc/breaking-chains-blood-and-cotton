# Criterios de aceptación de accesibilidad

- Texto base mínimo de 18 px en la resolución objetivo; escalado al 200 % sin truncamiento en interfaces críticas.
- Contraste mínimo objetivo de 4.5:1 para texto normal y 3:1 para texto grande; alto contraste opcional.
- Subtítulos activables, con tamaño, fondo, color, identificación de hablante y velocidad configurables.
- Toda señal sonora tiene indicador visual equivalente y viceversa.
- Remapeo completo de teclado y mando; no hay acción crítica sin alternativa.
- Toda pulsación rápida tiene alternativa de mantener, alternar o ventana ampliada.
- Velocidad de juego: 50 %, 75 %, 100 % y pausa en escenas no interactivas.
- Dificultad separada en presión temporal, lectura de pistas, navegación y requisitos económicos.
- Guardado automático al entrar y salir de escenas; reintento desde el último punto seguro.
- Pruebas con teclado, mando, navegación sin ratón, lector de pantalla y usuarios con discapacidades visuales, auditivas, motoras y cognitivas.
- Ningún final o contenido narrativo se bloquea por usar asistencia.
