# QA and Validation

## Content validation

Check stable IDs, required fields, references, classifications, dates, locations, faction links, objectives, failure states, success states, rewards, reputation effects, and deterministic tests.

## Narrative validation

Check canon preservation, historical classification, source coverage, agency, sensitivity, target-list consistency, Elias Vane ambiguity, regional ending, and the 340-person outcome.

## Determinism tests

Given identical save state, date, route, weather state, transport state, alert state, evidence profile, and player decisions, main outcomes must match exactly.

## Regression suite

Run validation after every content change. Include tests for mission graph reachability, rescue ledger integrity, route discovery, faction state transitions, evidence availability, and final campaign state.
